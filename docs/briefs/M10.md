## Goal

Falak gets a real browser of its own on the Mac node: Chromium through Playwright, with a **persistent profile
that is Falak's, not Elijah's Chrome**. With it Falak can:

1. **Read pages that need JavaScript.** `web.read_page` (urllib, no JavaScript) stays the fast first try. The
   browser reads what it can't.
2. **Read sites Elijah signed in to, in that profile.** He signs in once himself, in a visible window, including
   the college SSO and 2FA. Falak never sees, types or stores a password. First of all: **Canvas**, so `school`
   gets submission status, ECON's module dates and announcements, which the calendar feed misses.
3. **Look at a page.** A screenshot goes to the model the way the screen app's pictures do (in memory, deleted
   after the turn), and can be sent to Elijah with `falak__send_image`.
4. **Show Elijah the page.** "Show me" opens the same page in a visible window on his Mac, where he can read it,
   scroll or take over.
5. **Do things on a page, only with his yes.** Following a link is reading. Typing into a field, pressing a
   button or submitting a form acts for Elijah, so it asks first, with exactly what will be typed and pressed.

## 1. The browser app (Mac node, `runs_on = "node:browser"`)

**Runtime**
- Playwright (Python) with its Chromium. A new dependency, in a `browser` extra (`uv sync --extra browser`),
  which `bin/falak` adds the way it adds `voice` and `desk`. Add `falak browser setup`, which runs
  `playwright install chromium` into the node's folder (`PLAYWRIGHT_BROWSERS_PATH` under `FALAK_NODE_DIR`), and
  checks there are 2 GB free first.
- One persistent context, profile at `FALAK_NODE_DIR/browser/profile` (0700). It's a live login: never in the
  repo, never logged, never sent anywhere, and the terminal's secret guard denies it (add it to the secret paths).
- **Signed-in sites:** a list in `FALAK_NODE_DIR/browser/sites.json`. Only those sites are opened with the
  profile. Every other site gets a fresh, empty context, so a random page never sees his sessions. Port this from
  `legacy/jarvis/browser.py`.
- **Every request is checked**, not just the first URL: `page.route("**/*")` aborts anything `check_url` or the
  blocklist refuses (this Mac, the local network, banking). Port the checks from `web` into the browser app's
  own module (apps can't import each other), and add a test that the two copies refuse the same addresses.
- One browser at a time. It closes after `idle_minutes` (default 5) without use. Memory is measured and reported
  (section 5).

**Actions**
- **read(url)**, read, `untrusted_output = true`, `sends_data = true` (a URL leaves the Mac). Loads the page,
  waits for it to settle (network idle, capped at `load_seconds`, default 15), then returns the title, the
  readable text (capped at 15,000 characters) and up to 60 links, the same shape as `web.read_page`.
  `screenshot = true` adds a picture of the viewport.
- **sign_in(site)**, local, with undo (forgets the site). Adds the site to the list and opens a **visible**
  window at it. Elijah signs in, and the window closes when he says he's done or after 10 minutes. The result says
  what to do in one line.
- **sites()**, read. **forget_site(site)**, local, with undo where possible (the cookies go only with
  `falak browser reset`, a CLI command for Elijah).
- **show(url = "")**, local: the current page (or `url`) in a visible window on the Mac. Playwright can't make a
  headless context visible, so close it and reopen the profile headed at the same URL, and back again when the
  window closes.
- **act(url, steps, why)**, `outbound`, confirm: "On <site>: <steps in plain words>. It's to <why>. Go?" Steps
  are a short list: `fill(field, text)`, `press(button)`, `select(field, option)`, `check(box)`. Fields and
  buttons are found by their visible label or text, never by a selector the model invents. Each step is checked
  against the page before anything runs, and if one doesn't match exactly, nothing runs and the result says what
  the page has instead. The ask is bound to the exact steps by the existing confirmation code. Never a password
  field.
- A **session** (`[[sessions]]`, the M5 kind) `browse`, for looking around: `start(url)`, `sample` (text, links and
  a screenshot of where it is now), `stop`. Following a link (`follow(link_text)`) is a read action on the open
  session, because a link is a GET. Buttons and forms always go through `act`.
- **fetch_json(url)**, read, `share = true`, `tool = false`: a GET with the profile, for apps. Refuses anything that
  isn't GET or a site on the list. Returns the JSON, or `signed_out = true` when the site redirected to a
  sign-in page.

## 2. web hands over to the browser

- When `read_page` comes back thin (the page needs JavaScript), its text says "this page needs a browser; use
  browser__read". The model decides; `web` doesn't call the browser (it's a host app, the browser is a node app,
  and `ctx.call` is only for shared reads, which `read` is not).
- Keep M9's plain views of Google Docs and Drive folders (`jarvis/apps/web/plain.py`). They're faster than a
  browser and need no sign-in.

## 3. Canvas through the browser (school)

- `school` gets `uses = ["browser"]`. The sync job first tries `ctx.call("browser", "fetch_json", ...)` for the
  Canvas API, the same requests `/weekly` made (see `canvas-browser.md`):
  - assignments with submission status, for every current course
  - modules and module items, for ECON's dates in module titles ("Module 2: Chapters 3 & 4 (DUE OCT 11)")
  - announcements from the last 14 days, for extensions
- Port the parsing from `legacy/jarvis/canvas.py` (the API half). Rows from the browser are `source = 'canvas'`,
  `trackable = true` (they have submission status), and replace the feed's copy of the same assignment. A module
  title's date becomes a deadline with `kind = 'due'` when no assignment covers it. An announcement that moves a
  date is shown in the next check-in, not applied silently.
- `AppUnavailable` (no node) or `signed_out`: the sync falls back to the calendar feed, as now, and says once on
  Discord: "Canvas wants you to sign in again; say 'sign in to Canvas' at your Mac." Not again until it works.
- The 3-hours-before "still unsubmitted" nudge now works for Canvas rows that have submission status.

## 5. Tests

- `uv run pytest` passes with no Playwright browser, no network and no window. Put the browser behind a small
  interface and test with a fake.
- New tests:
  - a site not on the list opens in a fresh context; a listed one uses the profile.
  - request routing refuses `127.0.0.1`, `192.168.x.x`, a name that resolves to a private address, a redirect to
    one, and a banking site, for sub-requests too. The web and browser copies of the check agree.
  - `act`: asks with the steps in plain words; a step that doesn't match runs nothing; a password field is refused.
  - `fetch_json`: GET only, listed sites only, `signed_out` on a redirect to a login page.
  - school: browser rows replace feed rows, module-title dates become deadlines, announcements reach the next
    check-in, and a signed-out sync falls back to the feed and says so once.
  - `read_page` thin text points to `browser__read`.
- One opt-in test (skipped by default, run with `FALAK_BROWSER_LIVE=1`) that loads a public JavaScript page in
  real Chromium, in a scratch profile.
- Measure and write in `docs/browser.md`: RAM of the browser while reading a page, and time to read a JavaScript
  page cold and warm.
- **Never run against Falak-dev or Falak-node**, and never open Elijah's real profile. Scratch folders for everything.
